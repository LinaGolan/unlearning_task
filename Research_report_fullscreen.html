1Introduction

Removing a specific body of knowledge from a trained language model by retraining is expensive, so a tempting shortcut is to localize the knowledge to a few layers and disable only those. If that worked, unlearning would reduce to finding the right layer.

This report tests the premise on a concrete case: biosecurity knowledge in Llama-3.2-1B-Instruct, measured by WMDP-Bio, with eight high-school MMLU subjects standing in for the general ability we want to keep.

The question has two halves, and they are very different in difficulty. A localization method might find layers whose suppression damages WMDP-Bio more than randomly chosen layers do — that only requires the score to track importance. Or it might do that while sparing the retain set, which is what unlearning actually needs. The first is a reasonable hope; the second is a strong claim.

No clear advantage for selective unlearning over random layer selection was demonstrated. Gate (margin) causes more WMDP damage than random layers, but also more retain damage. The layer rankings are sensitive to which localization questions are used: splitting the set in half changes the selected layer in three of four cases. All four top-two gaps are below one estimated standard error.

The Gate (log-probability) score does not consistently track accuracy loss under strong interventions. Gate (margin) changes the ranking and produces larger WMDP losses at its selected strength, but retain losses also increase. Neither result establishes selective knowledge removal.

The two-layer selective intervention causes broad damage: WMDP accuracy falls by 76.95 points and retain accuracy by 78.91 points. Four layers also cause substantial retain damage. Neither budget provides evidence of selective forgetting at the development-selected strength.

2Method

Scoring how much each layer matters

Each decoder block adds a residual contribution to the stream, rℓ = hout − hin. Introducing a scalar gate that scales only that contribution makes gℓ = 1 the unmodified model and gℓ = 0 a model with block ℓ removed. Differentiating any scalar objective M(x) with respect to those gates gives, in a single backward pass, a per-layer sensitivity for question x:

h_out(g_ℓ) = h_in + g_ℓ · r_ℓ s_ℓ(x) = ∂M(x)/∂g_ℓ at g = 1 F_ℓ = mean over forget questions R_ℓ = mean over retain questions S_ℓ = F_ℓ − R_ℓ

A large positive Fℓ marks a layer the WMDP answer currently leans on. Sℓ is the selectivity score: it asks for reliance that is specific to biosecurity rather than shared with general knowledge, because a layer that matters everywhere is useless as an unlearning target however important it is.

The objective is where the method turns out to live or die, so two are compared. The first, Gate (log-probability), called gate in the code, uses the log probability of the correct answer letter normalized over the four options — the natural choice, and the quantity the evaluator scores. The second, Gate (margin), called gate_margin in the code, is identical except that M is the decision margin between the correct letter and its strongest rival, zcorrect − maxi≠correct zi. That distinction looks pedantic and is not: accuracy changes only when the sign of that margin flips, so the margin is the quantity that actually decides whether an answer is right.

Both are first-order estimates around the unmodified model. Nothing guarantees they rank layers correctly for the strong ablations ultimately applied, and averaging over questions lets a layer that matters intensely to a few be outranked by one that matters slightly to all. Section 4 measures both problems rather than assuming them away.

Intervening on a layer

The intervention is a forward hook that scales the selected block's residual contribution:

h' = h_in + (1 − α) · r_ℓ

At α = 0 the model is untouched; at α = 1 the block is skipped entirely. It is a generalized zero-ablation with α interpolating between the two, it accepts any set of layers and any strength, and the same loaded model is evaluated with the hook attached or removed. Because no weight is modified, α = 0 is bit-identical to the original model and detaching the hook restores it exactly.

That last point is also the study's main caveat: this is reversible suppression at inference time, not erasure from the weights. Nothing here speaks to whether the knowledge could be recovered.

3Experimental setup

The model is meta-llama/Llama-3.2-1B-Instruct at revision 9213176, in float32, with 16 decoder layers. The saved software environment is recorded in the run metadata. Its weights are frozen from start to finish.

The forget set is cais/wmdp, configuration wmdp-bio. The retain set is cais/mmlu across eight high-school subjects balanced as far as screening permits — US history, world history, geography, government and politics, microeconomics, psychology, physics and computer science — so that "general ability" means something broad rather than one narrow skill. A separate 64-question set of MMLU high-school biology is held back to distinguish losing WMDP knowledge from losing biology knowledge in general. Every dataset revision is pinned.

Questions are deduplicated by normalized text. The unmodified model first answers all 1,273 WMDP-Bio, 1,848 retain and 309 biology questions in their unshuffled order. Only correctly answered questions are tested under the other 23 answer orderings. Requiring correctness in the unshuffled order and at least 18 of 24 orderings leaves 567 WMDP, 754 retain and 115 biology questions. Fixed SHA-256 ranks select 512 WMDP, 512 retain and 64 biology questions. Retain subjects are uneven after screening: only 16 physics and 24 computer-science questions qualify.

The 18/24 threshold allows a 512-question forget set; requiring 24/24 would leave 408 WMDP questions. Farrell, Lau and Conmy (2024) motivated answer-order screening but used 24/24. Li et al. (2024) introduced WMDP. Permutations are used only for screening; subsequent stages use each selected question in its unshuffled order.

The selected WMDP and retain questions are then divided by SHA-256 rank into three disjoint sets that do three different jobs: 128 forget and 128 retain questions to compute the layer scores, another 128 and 128 to choose the intervention strength, and 256 and 256 held back for the numbers reported here, scored once with the layer and strength already fixed.

Scoring uses the original WMDP and MMLU zero-shot prompt, unmodified:

The following are multiple choice questions (with answers) about biology. {question} A. {choice A} B. {choice B} C. {choice C} D. {choice D} Answer:

The four continuations A, B, C and D are each a single token, and the code asserts that the answer-token boundary does not shift when a letter is appended to the exact prompt. The prediction is whichever of those four logits is highest, and the Gate (log-probability) objective is a log-softmax over just those four. Nothing is ever generated, and the correct answer never appears in the prompt.

Strength is chosen on the development questions, from the selectivity condition alone, by a rule fixed in advance: take the largest WMDP drop whose retain drop stays within five points, breaking ties toward the weaker intervention, and fall back to the largest WMDP-minus-retain margin if no strength qualifies. All four conditions within a method then share the same layer budget and the same strength.

Uncertainty is estimated using a paired bootstrap over questions with 2,000 resamples drawn with replacement. Each accuracy drop is recomputed on every resample, and the middle 95% of values gives the reported interval. All conditions use the same resampled questions, preserving their pairing when comparing interventions.

4Results

Drops are signed so that a positive number means worse accuracy: +5 pp is five percentage points lost, and a negative value means accuracy improved.

What the model knows to begin with

Before screening, the model answers 751 of 1,273 WMDP-Bio questions correctly (58.99%) and 1,042 of 1,848 retain questions (56.39%). On the selected held-out test questions, both accuracies are 100.00% (256 of 256); both development accuracies are also 100.00%. This follows from selecting questions the model already answered correctly, rather than an improvement in the model. The mean log probability of the correct letter is −0.267 on WMDP.

The baseline predicts A 56 times, B 70, C 66 and D 64. These counts describe its answer-position distribution; they do not rule out a position bias. Section 5 examines how the distribution changes under intervention.

Choosing a layer means taking a maximum over 16 noisy estimates, so the question that decides whether any of this is usable is not what the ranking looks like but whether the best layer is distinguishable from the runner-up. Each layer's score is a mean over questions, so it carries a standard error — the spread of the per-question values divided by the square root of how many there are. Comparing the gap between the top two layers against that error is what the table below does.

The Gate (log-probability) WMDP score has the largest top-two gap, at 0.32 estimated standard errors; all four gaps are below one. Recomputing each score on two disjoint halves selects a different layer in three of four cases. These results suggest unstable rankings, rather than proving that the layers have equal true scores.

It is worth being precise about what that does and does not mean. The pipeline is deterministic: the seeds are fixed, so re-running it selects the same layer every time. What is unstable is the answer to a different question — whether the same layer would be chosen from a different sample of questions — and no seed can help with that, because a seed fixes which questions are drawn, not whether that many questions are enough to decide.

The last column is a rough extrapolation using the inverse-square-root relationship between standard error and sample size. It estimates 6,321 questions in each of the forget and retain sets for Gate (log-probability)'s selectivity score, and 19,277 WMDP questions for Gate (margin)'s forget-only score. Both exceed the 1,273 questions in WMDP-Bio. These estimates omit covariance between layer scores and adjustment for selecting among 16 layers, so they do not establish a hard sample-size requirement or prove that more data could not help.

With that caveat recorded, the selections used below are, zero-based: the Gate (log-probability) method picks layer 10 as most important, layer 5 as most selective and layer 15 as least important; the Gate (margin) method picks layer 10, layer 1 and layer 15 respectively. The five random controls drew layers 6, 12, 1, 2 and 4.

Both methods choose the same most-important and least-important layers, so those interventions coincide when compared at the same strength. Random seed 303 also draws layer 1, Gate (margin)'s most-selective layer. With 16 layers and five seeds, such overlaps are possible and are retained in the random control.

5Causal validation and robustness

Causal effects on behavior do not establish knowledge removal. The intervention changes activations while keeping the model weights and questions fixed. Zero strength reproduces the baseline, and gate gradients agree with finite differences. These checks support correct implementation, but cannot exclude every intervention artifact or distinguish stored knowledge from general computation.

General degradation remains a plausible explanation. Strong single-layer interventions cause substantial losses on both datasets, as do the two- and four-layer selective conditions in Table 6. In the 64-question biology control, Gate (margin)'s selected intervention loses 76.56 points [65.62, 85.94] from a 100.00% baseline; random layers lose 55.94 [49.69, 61.88]. These results do not establish a biosecurity-specific effect.

Prompt robustness is mixed. The most-selective interventions are held fixed: layer 5 at α = 0.25 for Gate (log-probability), and layer 1 at α = 1.0 for Gate (margin). They are evaluated on the same fixed subset of screened test questions using the original prompt and two chat formats:

Gate (margin)'s point estimates remain positive under all three formats, although the no-pre-fill interval includes zero. Retain accuracy also falls by 61.90 points under the pre-filled chat format, so consistent direction alone does not demonstrate selective forgetting.

Answer-position effects remain possible. On the main test set, Gate (margin)'s most-selective intervention raises the number of B predictions from 70 to 118. This motivates the answer-permutation experiment in Section 7, but the count change alone cannot distinguish a position bias from changed knowledge or reasoning.

Distributed or redundant representations remain possible. The weak selectivity of single-layer interventions and the damage at larger budgets are compatible with these explanations, but do not establish them. A mismatch between gradient scores and finite interventions is another limitation; Appendix A examines it directly.

6Limitations

  • Layer selection is unstable. Several layer scores are not clearly separated relative to their estimated uncertainty, and splitting the localization questions into two halves changes the selected layer in three of four rankings.

  • Resolving the rankings may require more data than the benchmark provides. The estimates suggest 6,321 questions in each of the forget and retain sets for Gate (log-probability)'s selectivity score, and 19,277 WMDP-Bio questions for Gate (margin)'s forget-only score. WMDP-Bio contains only 1,273 questions. These are approximate extrapolations, not guaranteed requirements.

  • The scores have methodological limits. Selectivity combines uncertainty from two estimated means. Gradient scores describe small changes around the original model, so they may poorly predict strong interventions. For layer 15, correct-answer log probability improves under suppression while accuracy falls.

  • The interventions do not isolate knowledge precisely. Changing an entire block affects both stored information and computations passing through it.

  • Permanent forgetting was not demonstrated. Model weights remain unchanged, and the study does not establish permanent knowledge removal or resistance to relearning.

  • Statistical conclusions are limited. Confidence intervals hold the model, subjects, selected layers, and five random controls fixed; they exclude uncertainty from repeating localization. No correction was applied for multiple comparisons. No development-selected selective condition establishes a useful forget–retain trade-off.

  • Generalization remains uncertain. The study covers one small model and one target domain. Both benchmarks are public and may have appeared in pretraining, so baseline accuracy is not a clean measure of underlying knowledge.

  • Screening restricts the population being evaluated. The 100% selected baseline is conditional on answering the screening questions correctly; it is not a full-benchmark improvement. Retain subjects are uneven after screening. The 24 orderings are correlated and are not treated as independent test examples.

7What I would do next

The controls narrow the field but cannot separate a content-specific effect from disruption of how the model picks an answer, and the letter shift under the Gate (margin) method makes that the live question. A balanced permutation test on fresh questions would help distinguish these explanations. The 24-order baseline screening does not answer this question because it applied no intervention.

  1. Freeze the selected layer and strength, and draw fresh biosecurity and retain questions used nowhere in this study.
  2. For each question generate all four cyclic rotations of the answer choices, remapping the correct label each time, so identical answer content appears under every letter.
  3. Score every rotation with and without the intervention, bootstrapping at the level of the original question because the four rotations are not independent.
  4. Report accuracy averaged over rotations, whether the chosen content stays the same as it moves, and the letter distribution.

If errors track answer letters or positions as the same content moves between slots, that would support an answer-selection explanation. If the effect persists across rotations while matched retain performance is preserved, that would support a content-specific effect. Accuracy falling on both datasets would support general degradation. These outcomes would narrow the explanations, but would not by themselves prove that knowledge was erased or localized to a particular layer.

Two findings motivate follow-up. Gate (margin)'s least-important layer causes less damage than random selection on both datasets, with unadjusted paired intervals excluding zero. This supports its identification as a relatively low-impact target in this setup, rather than showing that the method can identify knowledge-specific layers.

The selective ranking does not show that the retain signal avoids collateral damage: its larger WMDP losses are accompanied by greater retain losses. Replication on fresh questions is needed before treating the layer rankings as reliable, and the screened population limits generalization.

9Reproducing this

results_fullscreen/selected_config.json fixes model and dataset revisions, split sizes, strengths, random seeds and the bootstrap seed. Questions are assigned to splits by SHA-256 rank. The data manifest records checksums for the prepared question files and downloaded sources. Screening statistics and selected questions are saved in results_fullscreen/.

To regenerate the submitted numerical results from saved predictions, install the dependencies and run the following commands. These do not load the model or require a Hugging Face token:

python -m pip install -r requirements.txt python -m pip install -e . --no-deps python -m unlearning report --out results_fullscreen_experiment/main --figures results_fullscreen_experiment/main/figures python -m unlearning report --methods gate --out results_fullscreen_experiment/k2 --figures results_fullscreen_experiment/k2/figures python -m unlearning report --methods gate --out results_fullscreen_experiment/k4 --figures results_fullscreen_experiment/k4/figures

The commands regenerate analysis JSON, CSV and Markdown tables, and figures for the main, two-layer and four-layer runs. Appendix A is generated from the saved log probabilities and localization scores. This HTML narrative is maintained separately.

The README documents fresh model runs on a local machine, and notebooks/full_screening.ipynb provides a Colab workflow. Fresh runs should use a new output directory; existing prediction files are reused when resuming. Access to the configured model is required for inference. Different dependency versions and execution environments can affect fresh predictions, so identical outcomes across arbitrary setups are not guaranteed.

The submitted evidence includes 170 per-question prediction files across the three runs. Regenerating their analyses checks the recorded numerical results; it does not substitute for independently rerunning model inference.

AGradient prediction diagnostic

Gate (log-probability) predicts the mean drop in correct-answer log probability as α × Fℓ. The measured drop is the mean log probability before intervention minus the mean after intervention. Positive values mean the correct answer becomes less probable; negative values mean it becomes more probable. These quantities are measured in nats, while accuracy drops are in percentage points.

These observations show that this local score can poorly predict strong interventions and that log-probability changes need not track accuracy changes in this experiment.
