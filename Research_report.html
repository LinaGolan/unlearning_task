1Introduction

Removing a specific body of knowledge from a trained language model by retraining is expensive, so a tempting shortcut is to localize the knowledge to a few layers and disable only those. If that worked, unlearning would reduce to finding the right layer.

This report tests the premise on a concrete case: biosecurity knowledge in Llama-3.2-1B-Instruct, measured by WMDP-Bio, with eight high-school MMLU subjects standing in for the general ability we want to keep.

The question has two halves, and they are very different in difficulty. A localization method might find layers whose suppression damages WMDP-Bio more than randomly chosen layers do — that only requires the score to track importance. Or it might do that while sparing the retain set, which is what unlearning actually needs. The first is a reasonable hope; the second is a strong claim.

No statistically clear advantage over random layer selection was demonstrated. The layer rankings are sensitive to which localization questions are used: splitting the set in half changes the selected layer in all four cases. Three of the four top-two gaps are below one estimated standard error.

The Gate (log-probability) score does not consistently track accuracy loss under strong interventions. Gate (margin) changes the ranking and produces larger WMDP losses at its selected strength, but retain losses also increase. Neither result establishes selective knowledge removal.

The two-layer selective intervention provides evidence of selectivity in this run: WMDP accuracy falls by 5.86 points with no observed retain drop. It also reduces retain damage relative to forget-only selection. However, an advantage over random selection is not statistically clear, and the result has not been established across budgets.

2Method

Scoring how much each layer matters

Each decoder block adds a residual contribution to the stream, rℓ = hout − hin. Introducing a scalar gate that scales only that contribution makes gℓ = 1 the unmodified model and gℓ = 0 a model with block ℓ removed. Differentiating any scalar objective M(x) with respect to those gates gives, in a single backward pass, a per-layer sensitivity for question x:

h_out(g_ℓ) = h_in + g_ℓ · r_ℓ s_ℓ(x) = ∂M(x)/∂g_ℓ at g = 1 F_ℓ = mean over forget questions R_ℓ = mean over retain questions S_ℓ = F_ℓ − R_ℓ

A large positive Fℓ marks a layer the WMDP answer currently leans on. Sℓ is the selectivity score: it asks for reliance that is specific to biosecurity rather than shared with general knowledge, because a layer that matters everywhere is useless as an unlearning target however important it is.

The objective is where the method turns out to live or die, so two are compared. The first, Gate (log-probability), called gate in the code, uses the log probability of the correct answer letter normalized over the four options — the natural choice, and the quantity the evaluator scores. The second, Gate (margin), called gate_margin in the code, is identical except that M is the decision margin between the correct letter and its strongest rival, zcorrect − maxi≠correct zi. That distinction looks pedantic and is not: accuracy changes only when the sign of that margin flips, so the margin is the quantity that actually decides whether an answer is right.

Both are first-order estimates around the unmodified model. Nothing guarantees they rank layers correctly for the strong ablations ultimately applied, and averaging over questions lets a layer that matters intensely to a few be outranked by one that matters slightly to all. Section 4 measures both problems rather than assuming them away.

Intervening on a layer

The intervention is a forward hook that scales the selected block's residual contribution:

h' = h_in + (1 − α) · r_ℓ

At α = 0 the model is untouched; at α = 1 the block is skipped entirely. It is a generalized zero-ablation with α interpolating between the two, it accepts any set of layers and any strength, and the same loaded model is evaluated with the hook attached or removed. Because no weight is modified, α = 0 is bit-identical to the original model and detaching the hook restores it exactly.

That last point is also the study's main caveat: this is reversible suppression at inference time, not erasure from the weights. Nothing here speaks to whether the knowledge could be recovered.

3Experimental setup

The model is meta-llama/Llama-3.2-1B-Instruct at revision 9213176, in float32, with 16 decoder layers. The saved software environment is recorded in the run metadata. Its weights are frozen from start to finish.

The forget set is cais/wmdp, configuration wmdp-bio. The retain set is cais/mmlu across eight high-school subjects in equal proportion — US history, world history, geography, government and politics, microeconomics, psychology, physics and computer science — so that "general ability" means something broad rather than one narrow skill. A separate 64-question set of MMLU high-school biology is held back to distinguish losing WMDP knowledge from losing biology knowledge in general. Every dataset revision is pinned.

Questions are deduplicated by normalized text and then divided by SHA-256 rank into three disjoint sets that do three different jobs: 128 forget and 128 retain questions to compute the layer scores, another 128 and 128 to choose the intervention strength, and 256 and 256 held back for the numbers reported here, scored once with the layer and strength already fixed.

Scoring uses the original WMDP and MMLU zero-shot prompt, unmodified:

The following are multiple choice questions (with answers) about biology. {question} A. {choice A} B. {choice B} C. {choice C} D. {choice D} Answer:

The four continuations A, B, C and D are each a single token, and the code asserts that the answer-token boundary does not shift when a letter is appended to the exact prompt. The prediction is whichever of those four logits is highest, and the localization objective is a log-softmax over just those four. Nothing is ever generated, and the correct answer never appears in the prompt.

Strength is chosen on the development questions, from the selectivity condition alone, by a rule fixed in advance: take the largest WMDP drop whose retain drop stays within five points, breaking ties toward the weaker intervention, and fall back to the largest WMDP-minus-retain margin if no strength qualifies. All four conditions within a method then share the same layer budget and the same strength.

Uncertainty is estimated using a paired bootstrap over questions with 2,000 resamples drawn with replacement. Each accuracy drop is recomputed on every resample, and the middle 95% of values gives the reported interval. All conditions use the same resampled questions, preserving their pairing when comparing interventions.

4Results

Drops are signed so that a positive number means worse accuracy: +5 pp is five percentage points lost, and a negative value means accuracy improved.

What the model knows to begin with

On the held-out test questions the model answers 60.55% of WMDP-Bio correctly (155 of 256) and 53.91% of the retain set (138 of 256). On the development questions the figures are 54.69% and 52.34%. Both are well above chance, so there is real accuracy available to remove, and the mean log probability of the correct letter is −1.066 on WMDP.

The baseline predicts A 44 times, B 88, C 60 and D 64. These counts describe its answer-position distribution; they do not rule out a position bias. Section 5 examines how the distribution changes under intervention.

The two objectives disagree sharply, most visibly about the final layer: the Gate (log-probability) score ranks layer 15 highest of all, while the Gate (margin) score ranks it lowest by a wide margin. Layer 15 writes directly into the final normalization and unembedding, so weakening it moves logits a great deal; whether that changes any answer is a different question, and the strength sweep below shows it barely does.

Choosing a layer means taking a maximum over 16 noisy estimates, so the question that decides whether any of this is usable is not what the ranking looks like but whether the best layer is distinguishable from the runner-up. Each layer's score is a mean over questions, so it carries a standard error — the spread of the per-question values divided by the square root of how many there are. Comparing the gap between the top two layers against that error is what the table below does.

The Gate (log-probability) WMDP score has the largest top-two gap, at 1.46 estimated standard errors; the other three gaps are below one. Recomputing each score on two disjoint halves selects a different layer in all four cases. These results suggest unstable rankings, rather than proving that the layers have equal true scores.

It is worth being precise about what that does and does not mean. The pipeline is deterministic: the seeds are fixed, so re-running it selects the same layer every time, and Section 9 confirms two runs agreeing exactly. What is unstable is the answer to a different question — whether the same layer would be chosen from a different sample of questions — and no seed can help with that, because a seed fixes which questions are drawn, not whether that many questions are enough to decide.

The last column is a rough extrapolation using the inverse-square-root relationship between standard error and sample size. It estimates 1,297 questions in each of the forget and retain sets for Gate (log-probability)'s selectivity score, and 5,168 WMDP questions for Gate (margin)'s forget-only score. Both exceed the 1,273 questions in WMDP-Bio. These estimates omit covariance between layer scores and adjustment for selecting among 16 layers, so they do not establish a hard sample-size requirement or prove that more data could not help.

With that caveat recorded, the selections used below are, zero-based: the Gate (log-probability) method picks layer 15 as both most important and most selective and layer 6 as least important; the Gate (margin) method picks layer 7, layer 2 and layer 15 respectively. The five random controls drew layers 6, 12, 1, 2 and 4.

Two coincidences in those selections are worth naming so the tables below are read correctly. For the Gate (log-probability) method the two rankings pick the same layer, so its "most important" and "most selective" conditions are the same intervention and cannot differ. And random seed 101 happened to draw layer 6, which is also that objective's least-important layer, so its random control contains its own bottom condition. With 16 layers and five seeds, collisions like these are likely rather than unlucky.

The two-layer selective condition provides evidence of selectivity in this run (RQ2). At α = 0.5, Gate (log-probability) reduces WMDP accuracy by 5.86 points [1.95, 10.16] with a retain drop of 0.00 [−5.08, +5.08]. The zero point estimate means no net accuracy change on the evaluated retain set; it does not establish zero damage in general. Random selection produces a similar WMDP drop (5.94 points) and a larger retain drop (2.58), but the paired interval for the selective condition's retain saving versus random is [−1.09, +6.25], so that advantage is not statistically clear.

Relative to forget-only selection (RQ3), the two-layer selective condition saves 12.11 retain points [+5.86, +18.36], while the WMDP-drop point estimate is smaller: 5.86 versus 9.38 points. The retain-saving estimate is zero at one and four layers; at four layers both conditions cause large accuracy losses. This is a promising result for follow-up, with multiple comparisons and uncertainty across budgets limiting the conclusion.

5Causal validation and robustness

Causal effects on behavior do not establish knowledge removal. The intervention changes activations while keeping the model weights and questions fixed. Zero strength reproduces the baseline, and gate gradients agree with finite differences. These checks support correct implementation, but cannot exclude every intervention artifact or distinguish stored knowledge from general computation.

General degradation remains a plausible explanation. Strong single-layer interventions cause substantial losses on both datasets; the two-layer selective result in Table 6 is a more favorable observed trade-off. In the 64-question biology control, Gate (margin)'s selected intervention loses 7.81 points [−4.69, +20.31] from a 51.56% baseline; random layers lose 10.63 [+2.81, +19.06]. These results do not establish a biosecurity-specific effect, and uncertainty for the selected intervention remains wide.

Prompt robustness is mixed. The most-selective interventions are held fixed: layer 15 at α = 0.25 for Gate (log-probability), and layer 2 at α = 0.75 for Gate (margin). They are evaluated on the same outcome-independent subset using the original prompt and two chat formats:

Gate (log-probability)'s estimated WMDP drop changes from +3.25 points to −1.63, suggesting sensitivity to prompt format. Gate (margin)'s point estimates remain positive under all three formats, although two intervals include zero. Retain accuracy also falls by 12.61 points under the pre-filled chat format, so consistent direction alone does not demonstrate selective forgetting.

Answer-position effects remain possible. On the main test set, Gate (margin)'s most-selective intervention raises the number of A predictions from 44 to 79. This motivates the answer-permutation experiment in Section 7, but the count change alone cannot distinguish a position bias from changed knowledge or reasoning.

Distributed or redundant representations remain possible. The weak selectivity of single-layer interventions and the damage at larger budgets are compatible with these explanations, but do not establish them. A mismatch between gradient scores and finite interventions is another limitation; Appendix A examines it directly.

6Limitations

  • Layer selection is unstable. Several layer scores are not clearly separated relative to their estimated uncertainty, and splitting the localization questions into two halves changes the selected layer in all four rankings.

  • Resolving the rankings may require more data than the benchmark provides. The estimates suggest 1,297 questions in each of the forget and retain sets for Gate (log-probability)'s selectivity score, and 5,168 WMDP-Bio questions for Gate (margin)'s forget-only score. WMDP-Bio contains only 1,273 questions. These are approximate extrapolations, not guaranteed requirements.

  • The scores have methodological limits. Selectivity combines uncertainty from two estimated means. Gradient scores describe small changes around the original model, so they may poorly predict strong interventions. Gate (log-probability) even predicts the wrong direction for layer 6 at full strength.

  • The interventions do not isolate knowledge precisely. Changing an entire block affects both stored information and computations passing through it.

  • Permanent forgetting was not demonstrated. Model weights remain unchanged, and the study does not establish permanent knowledge removal or resistance to relearning.

  • Statistical conclusions are limited. Confidence intervals hold the model, subjects, selected layers, and five random controls fixed; they exclude uncertainty from repeating localization. No correction was applied for multiple comparisons. The selectivity benefit appeared only at the two-layer budget, not at one or four layers.

  • Generalization remains uncertain. The study covers one small model and one target domain. Both benchmarks are public and may have appeared in pretraining, so baseline accuracy is not a clean measure of underlying knowledge.

7What I would do next

The controls narrow the field but cannot separate a content-specific effect from disruption of how the model picks an answer, and the letter shift under the Gate (margin) method makes that the live question. A balanced permutation test on fresh questions would help distinguish these explanations.

  1. Freeze the selected layer and strength, and draw WMDP-Bio and retain questions used nowhere in this study.
  2. For each question generate all four cyclic rotations of the answer choices, remapping the correct label each time, so identical answer content appears under every letter.
  3. Score every rotation with and without the intervention, bootstrapping at the level of the original question because the four rotations are not independent.
  4. Report accuracy averaged over rotations, whether the chosen content stays the same as it moves, and the letter distribution.

If errors track answer letters or positions as the same content moves between slots, that would support an answer-selection explanation. If the effect persists across rotations while matched retain performance is preserved, that would support a content-specific effect. Accuracy falling on both datasets would support general degradation. These outcomes would narrow the explanations, but would not by themselves prove that knowledge was erased or localized to a particular layer.

Two findings motivate follow-up. Gate (margin)'s least-important layer causes less damage than random selection on both datasets, with unadjusted paired intervals excluding zero. The two-layer selectivity result suggests that the retain signal can help avoid collateral damage. However, its advantage is specific to one tested budget and was found among multiple comparisons. Replication on fresh questions is needed before treating it as a reliable benefit.

9Reproducing this

configs/experiment.json fixes model and dataset revisions, split sizes, strengths, random seeds and the bootstrap seed. Questions are assigned to splits by SHA-256 rank. The data manifest records checksums for the prepared question files and downloaded sources.

To regenerate the submitted numerical results from saved predictions, install the dependencies and run the following commands. These do not load the model or require a Hugging Face token:

python -m pip install -r requirements.txt python -m pip install -e . --no-deps python -m unlearning report python -m unlearning report --methods gate --out results/k2 --figures results/k2/figures python -m unlearning report --methods gate --out results/k4 --figures results/k4/figures

The commands regenerate analysis JSON, CSV and Markdown tables, and figures for the main, two-layer and four-layer runs. Appendix A is generated from the saved log probabilities and localization scores. This HTML narrative is maintained separately.

The README documents fresh model runs on a local machine, and notebooks/experiment.ipynb provides a Colab workflow. Fresh runs should use a new output directory; existing prediction files are reused when resuming. Access to the configured model is required for inference. Different dependency versions and execution environments can affect fresh predictions, so identical outcomes across arbitrary setups are not guaranteed.

The submitted evidence includes 170 per-question prediction files across the three runs. Regenerating their analyses checks the recorded numerical results; it does not substitute for independently rerunning model inference.

AGradient prediction diagnostic

Gate (log-probability) predicts the mean drop in correct-answer log probability as α × Fℓ. The measured drop is the mean log probability before intervention minus the mean after intervention. Positive values mean the correct answer becomes less probable; negative values mean it becomes more probable. These quantities are measured in nats, while accuracy drops are in percentage points.
